## Состояние запуска

`scripts/run_background.ps1` остановлен для подготовки документов.
Историческое состояние запуска можно смотреть
в `output/background/status.json`, PID — в `output/background/pid.json`.
Журналы: `output/background/all.stdout.log` и `all.stderr.log`.
Состояние `running` означает незавершённую работу; `failed` — ошибку;
`computations_completed` — успешное завершение вычислительного конвейера.

При повторном запуске процесс возобновляет сохранённые результаты и
завершает малый сертификат, основные решения, сравнения, устойчивость,
игру, все эксперименты, отчёт и проверку комплектности. Лимит общей
продолжительности не задан: действуют согласованные критерии стагнации.
Для продолжения после перезагрузки или ошибки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/run_background.ps1
```

Не запускать параллельно второй полный конвейер. Обычный запуск:

```powershell
uv run --locked python scripts/run_project.py all
```
