# Исходное состояние проверок качества

Это исторический снимок до исправлений. Текущие журналы модели 2.1:
`output/quality/model_v2_lint.txt`, `model_v2_format.txt`,
`model_v2_types.txt`, `model_v2_tests.txt`. Последний полный запуск:
Ruff/format/mypy проходят, проверены 37 Python-файлов и 27 тестов.
Исходные ошибки ниже сохранены для истории, а не как текущий статус.

Дата: 25.10.2026. Проверки выполнены после добавления стандартов и конфигурации,
без изменения Python-скриптов и математической модели. Это исходный список
работ для этапа 1 из [плана](IMPLEMENTATION_PLAN.md), а не отметка о готовности.

## Окружение и команды

- Python 3.11, существующая `.venv`, uv; Ruff 0.17.2, mypy 2.4.0.
- Ruff/mypy и stubs добавлены через `uv add --dev`; версии записаны в `uv.lock`.
- Использован локальный кэш uv из-за ограничений доступа среды к общему кэшу.
- `uv --cache-dir .cache/uv-analysis lock --check --offline` — код 0:
  lock-файл согласован с конфигурацией.

Запущены команды:

```powershell
uv --cache-dir .cache/uv-analysis run --locked ruff check .
uv --cache-dir .cache/uv-analysis run --locked ruff format --check .
uv --cache-dir .cache/uv-analysis run --locked mypy
```

В машинном отчёте Ruff дополнительно использованы `--output-format json`
и `--output-file output/quality/ruff.json`; вывод двух других команд сохранён
в текстовые журналы. Коды завершения относятся к инструментам, а не к записи
или чтению этих журналов.

- 161 ошибка операций с типами; 17 несовместимых присваиваний;

  импортов не добавлялось. Способ типизации этой границы выбрать при работе
