# Презентация защиты: сеть пассажирских дронопортов

Актуальная версия:
[презентация и речь](final20/README.md). Всего 20 слайдов. Основной доклад содержит
13 слайдов и занимает около 10 минут. Остальные слайды нужны для вопросов.
Ниже описана сохранённая предыдущая версия.

Доклад на русском языке рассчитан примерно на 18 минут. Основная часть:
слайды 1–23. Слайды 24–28 предназначены для ответов на вопросы и в это время
не входят. Текст выступления и плановое время каждого слайда находятся
в заметках PowerPoint и в `speaker_notes.md`.

## Файлы для защиты

- [PowerPoint](droneports_presentation_ru.pptx): текст, таблицы и графики
  редактируются. На слайде 14 встроен анимированный GIF.
- [PDF](droneports_presentation_ru.pdf): та же последовательность слайдов;
  анимация представлена статическим кадром.
- [Текст выступления](speaker_notes.md): речь и источники по каждому слайду.
- [Речь в Word](speaker_notes_ru.docx): редактируемый текст по всем 28 слайдам.
- [Речь в PDF](speaker_notes_ru.pdf): 7 страниц для печати, с номерами слайдов
  и временем выступления. Резерв выделен отдельно.
- [Анимация отдельно](assets/schedule.gif): около 12 секунд, циклический показ.

Для анимации включите режим показа слайдов в PowerPoint. Проверка пакета
подтверждает сохранение всех 150 кадров GIF. Воспроизведение в конкретной
версии PowerPoint следует проверить перед выступлением. PDF не поддерживает
такую анимацию.

Речь и надписи используют короткие предложения, активные глаголы и единые
термины. Это гибкая адаптация принципов УТР примерно в запрошенной степени,
а не формальная сертификация или измерение процента соблюдения стандарта.

## Что учитывать при защите

Числа взяты из сохранённых результатов модели 2.1. Новая оптимизация для
презентации не запускалась. Малую задачу описываем через допустимое расписание
и корректную верхнюю границу. Остановку CBC не называем доказательством
оптимальности. Короткие дополнительные эксперименты не выдаём за полные
серии из десяти запусков. Спрос и цены являются учебными допущениями.

Известное ограничение проекта: окончания строк замороженных CSV влияют
на проверку хешей при переносе репозитория. Оно раскрыто на слайде 22;
создание презентации его не исправляет.

## Повторная сборка

Из корня проекта подготовить изображения и данные, без нового поиска:

```powershell
uv run --locked python -m scripts.build_presentation_data
node scripts/build_presentation.mjs presentation_ru_v2
```

Второй аргумент задаёт уникальный суффикс файла: финализатор не перезаписывает
ранее проверенные презентации. Исходники используют `@oai/artifact-tool`
и валидаторы из установленного набора Codex Presentations. Эта среда сборки
PowerPoint не входит в `uv.lock`. Экспорт PDF требует LibreOffice по пути,
указанному в JS-скрипте. Для открытия готовых файлов эти средства не нужны.

Расположение Node-модулей можно задать через `RUNTIME_NODE_MODULES`.
Временные страницы и протоколы финализатора сохраняются
в `tmp/presentation/`; итоговые файлы и материалы докладчика — здесь.
