# Презентация и речь для защиты

Это предыдущая версия. [Актуальная версия из 20 слайдов](../final20/README.md).

Основной доклад: слайды 1–13, около 10 минут. После слайда 13
выступление закончено. Слайды 14–30 открываются только при вопросах.
Они содержат карты первых двух лет, расходы, параметры и подробные
результаты проверок. Время основного доклада не включает этот резерв.

## Пояснения к докладу

Дневное расписание — список рейсов и зарядок на один рабочий день.
В каждом году используются восемь его вариантов. Семь повторяются
по 52 раза, ещё один — один раз. Получается 365 дней.
За три года проверяются 24 варианта. На слайде 8 показан один из них:
52 рейса, включая 23 рейса без пассажиров.

В игровой проверке сначала выбирается сеть, затем закрывается один порт
и пересчитываются перевозки. Альфа-бета-отсечение исключает лишние
проверки: если новая сеть уже хуже найденной, остальные отказы для неё
не могут сделать её лучшим выбором. На малой задаче проверены девять
конечных результатов вместо девятнадцати. Ответ остался тем же.

Случайность проверена десятью запусками поиска. Вместо сокращений
на слайдах указаны число запусков, единицы измерения и диапазон поездок.
Среднее и стандартное отклонение объясняются в речи к резервному слайду.

## Данные и проверка

Использованы сохранённые результаты модели 2.1. Новая оптимизация
не запускалась. Исходные данные v1 не изменялись. Спрос рассчитан
по учебной формуле, а найденные планы не объявлены точными максимумами.
На малой задаче сохранены план на 216 335 поездок, верхняя оценка
242 700,108 и разница 10,86% относительно верхней оценки.

В PowerPoint встроена анимация дневного расписания. В PDF показан
статический кадр. Для движения точек нужен режим показа PowerPoint.
Структура GIF проверена; воспроизведение в самом PowerPoint следует
проверить перед выступлением.

## Повторная сборка

Из корня проекта:

```powershell
node scripts/build_academic_presentation.mjs new_revision
```

Команда читает `content.json`, сохранённые результаты и изображения.
Для новой версии используйте новый суффикс: проверенные PPTX не
перезаписываются. Сохраняются презентация, PDF и Markdown с речью.
DOCX и PDF речи — отдельные печатные экспорты того же текста.
Нужны установленный набор Codex Presentations и LibreOffice.
Эти средства оформления не входят в зависимости математической модели.
